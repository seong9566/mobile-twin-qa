# QA 맥 앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mobile-twin-qa의 등록 → 계획 → 목록 확인 → 실행 → 결과 → 수정 요청 .md를 한 macOS 앱에서 한다.

**Architecture:** `app/`의 SwiftPM 패키지. 로직은 테스트 가능한 라이브러리 `QATwinCore`(파일 읽기·쓰기, Artemis REST, 실행 루프, Claude Code 실행), 화면은 실행 파일 `QATwinApp`(SwiftUI)이 맡는다. LLM 판단이 필요한 단계(등록·계획·준비·판정)는 `claude -p`로 기존 스킬을 부르고, Artemis 실행 루프는 앱이 직접 돈다.

**Tech Stack:** Swift 6.4, SwiftUI, AVKit, UserNotifications, Swift Testing(`import Testing`), macOS 27. 외부 패키지 없음.

**Spec:** `docs/superpowers/specs/2026-10-26-qa-mac-app-design.md`

## Global Constraints

- 회사 프로젝트 데이터는 이 맥 밖으로 내보내지 않는다. 테스트 fixture는 **지어낸 데이터**만 쓴다(`company/` 파일을 복사하지 않는다).
- `.env` 값은 화면·로그·`results.json`·.md·Claude Code 프롬프트에 넣지 않는다. 키 이름만.
- Artemis 쓰기(`POST /api/run`·`/api/stop`)는 승인 창에서 승인된 실행 안에서만, 지출 한도 도달 시 자동 정리와 사용자의 "중지"에서만. 기본 주소 `http://127.0.0.1:8100`. 8000은 쓰지 않는다.
- 멈춤 기준: `stdout.log` 5분(300초) 넘게 안 바뀜, 마지막 `Generated summary for Step` 뒤 `LLM stopped without calling any tool` 12회 이상. 감지 시 경고만, 앱이 스스로 멈추지 않는다.
- 앱은 비용 상한을 두지 않는다(사용자가 Console 월 지출 한도를 걸어 둠). Artemis 로그에 `You have reached your specified API usage limits` 또는 `enforced_spend_limit_reached`가 보이면 지금 시나리오 `보류`(사유 `API 지출 한도`), 남은 건 `미실행`(같은 사유).
- Claude Code 사용률: `~/.claude/.cc-sl-ratelimits` 한 줄 `<5h%> <5h 리셋 epoch> <7d%> <7d 리셋 epoch>`(없는 값은 `-`). 80% 이상 경고, 시작은 막지 않음. Claude 단계 USD 상한 없음.
- 원인 구분 값은 `앱 결함`·`도구 오판`·`환경` 셋(+없음). 결과 값은 `통과`·`실패`·`보류`·`미실행`.
- 모든 화면 문구·문서는 한국어. 코드 식별자는 영어.
- 원본 앱 repo에는 쓰지 않는다.
- 커밋: `git add`에 파일을 지정한다(`-A`·`.` 금지), 커밋 전 `git diff --cached --stat`, `Claude-Session:` 트레일러 없음. 이 작업은 워크트리 `.claude/worktrees/qa-mac-app` 브랜치에서 하고 PR로 머지한다.

## Review Focus

1. **실제 계획 파일 형식 차이** — 시나리오 제목이 `###`(양식)이 아니라 `#### ID · 제목`(실제 계획)이고, 등급이 `B(사람이 태그)`처럼 괄호가 붙는다. 둘 다 읽혀야 한다 → Task 2 테스트.
2. **`.env` 값에 `=`·따옴표·한글·공백** — 넣은 값이 `android-login.sh` 규칙대로(따옴표 한 쌍만 벗김) 그대로 읽혀야 하고, 다른 줄·주석은 남아야 한다. 줄바꿈이 든 값은 거부 → Task 4 테스트.
3. **Artemis가 꺼졌거나 폰이 잠겨 409** — 그 시나리오는 `보류`/`환경`과 사유로 적히고 실행은 끝까지 간다(무한 대기·크래시 없음) → Task 8 테스트.
4. **실행 중 "중지"나 앱 종료** — 진행 중 Artemis 세션에 stop을 보내고, `claude` 프로세스를 끝내고, `run-state.json`에 남은 건이 `미실행`으로 남는다 → Task 8·9 테스트.
5. **옛 `summary.md`의 비정형 값** — `통과 (키워드 단계 보류)`, 판정 `도구 이상`·`앱 결함 후보` 같은 값도 카드가 뜨고 원문이 보인다(원인은 비움) → Task 5 테스트.
